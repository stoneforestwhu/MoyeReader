# 墨页 · Windows EPUB 阅读器

参考双页纸质书布局制作的本地电子书阅读器，使用中文界面。内置原创示例书《山海之间》，首次运行即可体验。

## 使用

双击 `Moye-Reader-0.1.1-x64.exe` 运行，无需安装。点击右上角“打开书籍”选择 EPUB，也可以将文件拖入窗口。

- **目录**：显示书籍目录，支持章节筛选和点击跳转。
- **翻页**：点击纸张两侧箭头，或使用方向键、空格、Page Up / Page Down；底部可切换章节、拖动全书进度。
- **全文查找**：按 Ctrl+F，输入文字后回车；点击结果跳转并高亮。每次最多展示 500 处匹配。
- **阅读设置**：单页 / 双页、字号、宋体 / 黑体、行距，以及纸白、暖纸和夜间主题。
- **阅读记录**：自动保存进度、排版设置、最近打开的书和书签。

窗口较窄时双页自动变为单页。页数由当前窗口和字号实时计算；底部同时显示全书百分比和本章页数。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+O | 打开书籍 |
| Ctrl+F | 全文查找 |
| Ctrl+D | 添加 / 移除当前页书签 |
| Ctrl+B | 显示 / 隐藏侧栏 |
| ← / →、Page Up / Page Down | 上一页 / 下一页 |
| 空格 / Shift+空格 | 下一页 / 上一页 |
| Alt+← / Alt+→ | 上一章 / 下一章 |
| / | 筛选目录 |
| F11 | 全屏切换 |
| Esc | 关闭设置浮层 |

## 文件与范围

适用于 Windows x64，支持未加密的 EPUB 2 / EPUB 3 流式排版电子书，单文件上限 200 MB。DRM 加密书籍不支持。复杂固定版式、交互脚本、音视频并非本版的验证范围。

书籍留在原位置，阅读记录保存在 `%APPDATA%\墨页\reader-state.json`。移动原文件后需重新打开。书籍内容不会上传；书内脚本与网络请求被禁用。

这是未经代码签名的试用版本。内置示例文字为本项目原创，不包含参考截图中的书籍内容。

## 开发

使用 Node.js 22 或更新版本。

```powershell
npm ci
npm start
```

```powershell
npm test
npm run test:pagination
npm run dist
```

便携程序输出到 `release`。首次安装会下载 Electron，首次打包会下载 Windows 打包工具，需要网络。项目使用 Electron、epub.js、JSZip 和 esbuild；锁文件固定依赖版本。

`npm run test:pagination` 使用独立、隐藏的 Electron 窗口和测试阅读记录，在 125% / 150% 缩放、不同字号及单 / 双页模式下逐页检查章节末字和反向翻章。结果写入 `test-output/pagination-regression`。

0.1.1 修复章节交界处跳过末页的问题：翻页按绝对页位置计算，避免缩放时的小数像素误差累积；切换章节时等待阅读样式与字体排版完成，再定位章首页或末页。

`src/main.cjs` 负责窗口、文件与本地记录；`src/renderer.js` 负责排版、导航和查找；`src/styles.css` 负责界面；`scripts/demo.mjs` 生成 EPUB 2/3 测试书。
